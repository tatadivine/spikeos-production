# Approved Frontend Boundary

The contents of `frontend/` are taken from the approved SpikeOS Version 2 package supplied for this integration pass.

For this pass:

- Do not redesign or replace the frontend.
- Do not remove existing pages, components, routes, mock data, or services from the approved frontend.
- Outlook-specific runtime code belongs in `outlook-addin/`.
- Backend changes are limited to supporting Outlook/Graph integration and the side-panel data contract.
