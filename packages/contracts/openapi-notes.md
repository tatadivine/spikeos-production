# API Contract Notes

Primary endpoints:
- GET /health
- GET /api/v1/me
- POST /api/v1/outlook/context
- GET /api/v1/communications
- GET /api/v1/communications/{id}
- GET /api/v1/commitments
- POST /api/v1/commitments
- GET /api/v1/alerts
- GET /api/v1/team
- GET /api/v1/audit
- POST /api/v1/webhooks/graph

The FastAPI OpenAPI schema at `/docs` is the runtime contract.
